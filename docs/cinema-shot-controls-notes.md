# Cinema shot authoring decisions — 2026-10-08

- The selected-shot panel groups preview and variations in a media column, with prompt, generation, admission/upload feedback and motion handoff first in the editor. References and art direction follow. Scene-wide generation lives in the toolbar once.
- Enabling a palette/look override stores an empty partial override rather than copying the shared scene. Only edited fields become shot values; untouched fields continue to follow later scene changes. Reset removes only that override kind, keeping the other kind intact.
- Reusable `CinemaPaletteControls` and `CinemaLookControls` accept a value, a functional update and a label prefix. Scene/shot callers apply each update to the latest stored scene/shot, keeping concurrent output, variation, reference and sibling changes.
- Choosing a named film preset replaces the previous override with `{ preset }`. Its effective grade drops inherited custom floats and LUTs, matching the backend's named-preset merge. Explicit scalar/LUT overrides in imported recipes remain respected. Custom switches deliberately to editable values; unknown presets remain displayed without selecting a false known preset.
- Palette sliders, look sliders, swatches and reset buttons have distinct accessible names. Numeric values are plain text, avoiding `output`'s implicit status announcements for settings. Unknown saved palette methods remain an actual selector option.
- Custom film-look defaults are neutral zeroes, matching `cinema/look.py::_resolve_params`. Missing stored floats and an absent look display their actual neutral values; merely enabling an empty override or opening controls never writes a grade. Saved explicit fields remain untouched. Values are authored only by an explicit edit or Custom preset choice.
- No editor edit/reset starts generation or modifies previous output snapshots. Focused tests exercise actual graph-store updates, frozen run history, sibling output/variation preservation, inherited shared changes, named preset transitions and events dispatched from an older render. Upload and motion suites remain regression checks.
- Verification: 11 new shot art-direction tests; upload/motion suite totals and final project gates are recorded by the coordinating task. This slice uses local synthetic state, no provider/credential access, package changes or packaged Electron work.
