- **Total nodes:** 139

## Contract stack (all nodes)

Every node needs at minimum:

1. **Node contract** — id, category, `executionPattern`, ports, params (including `sharedParams` / `falParams` / `directParams` when present)
2. **Execution contract** — local-engine vs sync-handler vs async-registry mapping
3. **Handler contract** (if external API) — request/response mapping, auth key, poll/stream lifecycle
4. **Media contract** (if binary output) — download, cache path, preview component

## Gaps to close before handler ports

- **handler-file-unclear** — 24 nodes
- **no-provider-audit** — 14 nodes
- **no-backend-test** — 11 nodes
- **file-param-ipados** — 8 nodes
